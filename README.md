An intelligent AI assistant designed to interact with users, understand natural-language requests, and perform tasks through a modern web interface.

🚀 Overview

Cursio AI is a full-stack AI assistant project built to explore how modern AI systems can understand user requests and execute useful actions.

The project combines a conversational AI interface with a Spring Boot backend, allowing users to interact with the assistant through natural language.

The long-term goal is to evolve Cursio into a Jarvis-like personal AI assistant capable of conversation, automation, content generation, and intelligent task execution.
